# HotelReservationSystem
## Description:
This Java application allows users to manage hotel reservations. It allows customers to book rooms, check availability, and view booking details.

## Features:
- Check room availability.
- Book a room.
- View and cancel reservations.

## Technologies Used:
- Java

## How to Use:
1. Clone this repository:
   ```bash
   git clone https://github.com/rizwana07/HotelReservationSystem.git

2. Open the project in your preferred IDE (e.g., Eclipse, IntelliJ).


3. Locate and open the Main.java file.


4. Run the Main.java file to start the application.
